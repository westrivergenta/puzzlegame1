# スワップ4（まるおゲーム）

## 公開前にやること

1. `maruo-opening.js` と `maruo-ranking.js` はキットの v1.0.0 をそのまま同梱済み（改変なし）
2. `config.js` に、ほかのまるおゲームと同じ Project URL と公開用キー（`sb_publishable_…`）を入れる
   - 秘密のキー（`sb_secret_…` / `service_role`）は入れない
3. フォルダごと GitHub Pages などに公開する（ラマダッシュと同じアカウントにすると、ニックネームが共通になります）

## 仕様メモ

- gameId：`swap4`（公開後は変えない）
- ランキング対象：初級・中級・上級（スコア倍率込みの合計で1つのランキング）
- 無限モード：ランキングに送らない（参考ベストは端末内のみ）
- オフライン：初回に開いたときに全ファイルを保存。以後は機内モードでも起動・プレイ可能。
  オフライン中の自己ベストは端末に保存され、オンラインに戻ると自動で送信されます
- 更新したら `sw.js` の `VERSION` を上げる（例：`'v1'` → `'v2'`）
